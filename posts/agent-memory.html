Agents Need Episodic Memory, Not Bigger Context

For long tasks, an agent that can recall what happened beats one that can see more tokens.

Core claims

What should you remember, and what will an agent cite?

  1. C1A bigger context window delays forgetting; it doesn't fix it.
  2. C2Storing past runs as structured episodes beats replaying raw tokens.
  3. C3Memory should be written by the agent but owned by the user.

§1The context trap

Each time a model ships with a longer context window, the same idea comes back: if the agent can see everything, it doesn't need memory. That treats forgetting as a capacity problem when it's really a retrieval problemC1. Even with a million tokens, an agent still has to decide which forty of them matter right now.

1Usable context is usually much smaller than the advertised window. Attention spreads thin long before the limit.

In practice, long contexts fail quietly. The agent doesn't crash. It just gives a little less weight to the instruction you gave it three hours ago, and the drift builds up.[1]

A context window is a desk. Memory is a filing cabinet. You can't fix a messy office by buying a bigger desk.— notes, 2026.10

§2Episodes, not tokens

People don't remember transcripts. We remember episodes: what we tried, what happened, and what we would do differently next time. An agent that stores each run as a small structured record (goal, actions, outcome, lesson) can recall exactly the right past experienceC2, at a tiny fraction of the cost of replaying the whole transcript.

2An episode here is about 200 tokens of JSON, compared with roughly 40k tokens for the raw transcript.

§3A minimal design

You don't need a new framework. A table of episodes, an embedding column and one retrieval call at the start of each run cover most of the benefit. Keep the store in a place the user can read, edit and deleteC3. An agent's memory is a record of the user's work, so it should belong to the user.

Write episodes with remember(goal, outcome, lesson) and read them with recall(goal, k=3). Everything else is tuning.
